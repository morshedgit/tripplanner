# Wonderlog ChatGPT Plugin

A Wanderlog-inspired travel itinerary planner designed as a ChatGPT plugin, allowing users to create and manage their travel itineraries through a conversational chat interface.

## Planned Scope
- Trip & day-by-day itinerary management
- Places & notes saving (restaurants, attractions, lodging, transit)
- Expense tracking & group budget splitting
- Exportable itinerary summary & map links
